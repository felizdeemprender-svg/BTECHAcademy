> Única fuente de verdad para retomar el trabajo entre sesiones.

## Definición de "done" por objetivo (las 4 deben cumplirse)

1. **Capas:** `route.ts` ≤ ~25 líneas, solo `auth + resolveGateway → handler`. Cero `firebase/admin`, cero `firestore`, cero SDK (Stripe/MP/GetNet) en routes. `domain/` sin imports de `firebase` ni `next`.
2. **Compat esquema:** mismas colecciones/campos/subcolecciones. Prohibido renombrar campos, cambiar `status` (`active/suspended_by_system`), o unificar `subscriptionPlans`/`subscription-plans`. Evidencia: `git diff` no muestra cambios en nombres de colección/campo.
3. **Tests verdes ANTES del commit:** `npm test` + `npx playwright test` + `npx tsc --noEmit` sin errores nuevos. Cada fase añade/actualiza su `__tests__` (dominio) + test de repo (gateway fake) + test de handler + caso E2E de contrato si expone HTTP.
4. **Trazabilidad:** fila pasada a `✅ hecho+verde` con Fecha + hash de commit. Sin fila actualizada = no done.
